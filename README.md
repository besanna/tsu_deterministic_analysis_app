# Веб-приложение «Платформа для детерминационного анализа»

Веб-приложение предназначено для проведения детерминационного анализа данных социологических опросов на основе CSV-файлов.

## Описание доработки

В рамках ВКР выполнена доработка клиентской части приложения:

- добавлен модуль настройки конфигурации анализа;
- реализован выбор признаков для анализа;
- добавлены пороговые значения интенсивности и емкости;
- реализована вкладка «Ключевые выводы»;
- исправлено открытие сохраненного детерминационного анализа из истории;
- добавлены unit- и component-тесты для реализованных компонентов.

## Установка

Для установки нужных зависимостей воспользуйтесь командой:
```bash
npm install
```

Для запуска приложения воспользуйтесь командой:
```bash
npm start
```

После запуска приложение будет доступно в браузере по адресу:
```text
http://localhost:3000
```

## Проверка

Для запуска тестов реализованного модуля:
```bash
npm test -- --watchAll=false InsightsPanel.test.js AnalysisConfigForm.test.js list.test.js
```

Для сборки проекта:
```bash
npm run build
```
